# Coding Standards

- Python: follow PEP 8.
- Use type hints and docstrings.
- Keep functions focused and reusable.
- Use pathlib for filesystem paths.
- Use configuration files instead of
  hardcoded domains or URLs.
- Separate I/O from analytics.
- Write unit tests for core functions.
- Use deterministic seeds where applicable.
- Avoid unnecessary dependencies.
- Pin or constrain dependencies.
- Do not silently discard processing errors.
- Use structured logging.
- Validate external inputs.
- Never trust scraped HTML or AI output.
