# Notebook Development Rules

- Use Jupyter notebooks for all initial
  research and pipeline experimentation.
- Each notebook must have a clear objective.
- Explain every major step in Markdown
  before the code cell.
- Explain the output after the code cell.
- Include methodology and reasoning.
- Use meaningful variable names.
- Display representative outputs.
- Include charts where they add value.
- Interpret every important chart.
- Include error handling and limitations.
- Avoid giant, monolithic code cells.
- Make notebooks reproducible.
- Keep credentials out of notebook outputs.
- Use local sample datasets for tests.
- Do not use fabricated real-world results.
- Label synthetic data explicitly.
- Run all cells from top to bottom
  before declaring a notebook complete.
- Save the final executed notebook.
